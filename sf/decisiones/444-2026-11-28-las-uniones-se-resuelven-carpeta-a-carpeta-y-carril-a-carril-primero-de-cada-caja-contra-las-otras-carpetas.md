# Las uniones se resuelven carril a carril, de cada caja contra las otras carpetas, para que cualquier carpeta desplegada sola dé un diagrama correcto

Regla: el tercer nivel del dibujo (uniones, 442) empieza por la vista con una sola carpeta desplegada, sea cual sea. Para la carpeta abierta se resuelve carril a carril de qué caja suya sale cada flujo del carril y a qué caja suya llega cada uno de los que entran; cada flujo va de esa caja al borde de la otra carpeta, que está cerrada, no aún a las cajas de dentro de la otra. El resultado es que, con cualquier carpeta desplegada y las demás cerradas, el diagrama es correcto y completo. Se empieza por la primera carpeta para revisarla y se sigue con las demás. Las uniones entre cajas de dos carpetas abiertas a la vez son un paso posterior.

Porqué: mantener el procedimiento de arriba abajo también dentro del nivel de uniones: un carril y una carpeta cada vez, para que cada parte se pueda comprobar y no se mezcle la complejidad; y que cada paso deje un diagrama correcto que se pueda ver (norma del propietario, 28/11/2026, tarea 483).
