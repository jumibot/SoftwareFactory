# Una skill propia para los informes de las deliberativas, ligera sobre el diseño común

- **Origen:** SoftwareFactory, 2026-11-02. Al rediseñar el informe de «Tipos de tarea: tres familias, cómo usa el repositorio cada una y cómo se cierran» (274), que hubo que maquetar a mano, se preguntó si conviene una skill para este tipo de informes. El propietario: «me parece bien … pero hay que valorar si aligerar el fundacional y tener una skill general de recursos de diseño para documentos. Me gusta mucho el tema de la usabilidad de los docs … Creo que comunicar es vital para los proyectos».
- **Contexto:** una deliberativa da un informe con formato de fundacional («Una deliberativa da un informe con formato de fundacional y las tareas que salgan», 218). Cada informe se ha maquetado distinto y con HTML a mano: tarjetas, fichas de preguntas, partir lo abierto. Los tipos de tarea se agrupan en familias para tener agentes especializados («Siete tipos de tarea en tres familias», 223).
- **Decisión:** los informes de las tareas deliberativas (investigar, deliberar, diseñar) tienen su propia skill. Es ligera: reutiliza el generador y el diseño comunes y solo añade lo suyo: la estructura fija (resumen, lo decidido, lo abierto partido por importancia, separaciones, tareas que salen), las fichas de pregunta con opciones, recomendación y estado, y el ciclo de versión, respaldo y HTML en cada vuelta. Es la skill que carga el agente de esa familia. Queda por valorar, en la misma tarea, si se aligera el fundacional y se saca una skill general de recursos de diseño para documentos, que usarían el fundacional, la visión y los informes.
- **Consecuencias:** la usabilidad de los documentos es un objetivo de la SF: comunicar bien es vital para los proyectos. Las mejoras del formato fundacional pendientes («Informes de las deliberativas más fáciles de maquetar», 300) entran en esa tarea.
- **Aplicada en:** `sf:informe_deliberativa` (`scripts/informe_to_html.py`, `assets/plantilla-informe.md`); `sf:crear_documentos`; metodología, «Estructura documental común»; pendiente: que la use el agente de la familia deliberativa, que aún no existe.
