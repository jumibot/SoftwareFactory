# Una sesión con la SF apagada, y /sf_forzar_inactiva, dejan Claude Code sin más

Fecha: 2026-11-05. Decidida por el propietario de la Software Factory.

## Qué se decide

- Una sesión con la SF apagada es Claude Code sin más: no quedan encendidos el control de un proyecto por sesión, la regla del prompt de sistema ni el contexto de la SF.
- `/sf_forzar_inactiva` deja la sesión exactamente igual: Claude Code sin más.
- El único rastro de la SF es el aviso al apagarla (decisión 296).

## Por qué

Una SF a medias, con reglas y bloqueos pero sin tareas ni panel, confunde. Apagada quiere decir apagada.

## Opciones descartadas

- Dejar solo el control de proyecto.
- Dejar el control y la regla, con la cola bloqueada.
