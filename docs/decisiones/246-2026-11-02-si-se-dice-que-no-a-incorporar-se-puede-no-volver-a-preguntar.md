# Si se dice que no a incorporar, se puede no volver a preguntar

- **Origen:** SoftwareFactory, 2026-11-02. En «Primeros cinco minutos de un usuario nuevo con la SF» (289) se preguntó cuándo vuelve a preguntar Claude si el usuario dice que no a incorporar una carpeta sin SF («En una carpeta sin SF, Claude ofrece incorporarla», 243). El propietario eligió la opción de no preguntar más, «pero con una nota que se puede hacer cuando lo pida».
- **Contexto:** lo implementado preguntaba una vez por conversación. Se valoraron también preguntar una sola vez por carpeta, o añadir una opción de no volver a preguntar.
- **Decisión:** el menú tiene tres opciones: «Sí, incorporarlo», «Ahora no» (no vuelve a preguntar en la conversación) y «No, y no vuelvas a preguntar en esta carpeta» (se recuerda por carpeta). Con cualquiera de los dos «no», Claude añade una nota: el proyecto se puede incorporar cuando se pida, escribiendo «incorpora este proyecto a la SF».
- **Consecuencias:** el mod guarda por carpeta el «no vuelvas a preguntar»; la bienvenida del panel sigue mostrando cómo empezar.
- **Aplicada en:** la 289.
