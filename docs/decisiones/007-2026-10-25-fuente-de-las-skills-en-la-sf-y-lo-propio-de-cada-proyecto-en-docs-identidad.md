# Fuente de las skills en la SF y lo propio de cada proyecto en `docs/identidad/`

> **Sustituida en parte** el 2026-11-01 por «Skills externas: tal cual, como dependencias; adaptadas, como propias» (175) y «Todas las skills externas actuales, como dependencias» (176): una skill externa que se usa tal cual ya no tiene su fuente en la SF, sino que es una dependencia del plugin `sf`. Solo viajan en el plugin las versiones nuestras. Lo de las skills propias y `docs/identidad/` sigue vigente.

- **Origen:** SoftwareFactory, 2026-10-25.
- **Decisión:** todas las skills, propias y externas (también las de apoyo, GSAP y three.js), tienen su fuente versionada en la SF. Lo propio de cada proyecto (tema, logo, producto, reglas del dominio) vive en su `docs/identidad/`, nunca en la skill.
- **Consecuencias:** la instalación por copia en `~/.claude/skills/` quedó **sustituida** el 2026-10-27 por el plugin `sf`.
- **Aplicada en:** especificación, 2; metodología, 6; visión.
