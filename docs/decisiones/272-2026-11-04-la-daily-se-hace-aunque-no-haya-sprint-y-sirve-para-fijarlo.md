# La daily se hace aunque no haya sprint y sirve para fijarlo

La daily (al abrir Claude Code o con /sf_daily) se hace siempre, haya sprint o no. Sin sprint, resume lo que hay en curso y en cola y es el momento de fijar uno: Claude propone los candidatos a objetivo con su recomendación y el developer decide. Precisa la 261 y la 271 (tarea 347).

Por qué: el momento natural para centrar el foco es cuando el developer se sitúa; no hace falta un paso aparte para crear el sprint.
