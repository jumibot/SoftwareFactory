# La orden fija del plugin se llama /sf:panel

La orden fija que el plugin trae para abrir el panel antes de que arranque el mod se llama /sf:panel: Claude Code antepone siempre el nombre del plugin (sf:) a sus órdenes, así que no puede llamarse /sf a secas, y «panel» dice lo que hace mejor que /sf:sf. Con el mod en marcha sigue existiendo /sf, que el mod registra sin prefijo; /sf:panel no aparece repetida en la lista.

Precisa la decisión 254 (tarea 337).
