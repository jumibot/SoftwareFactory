# Dos roles de color para un primario claro: sobre-primario y primario-texto

El estilo tiene dos roles de color más, sobre-primario (el texto encima del primario) y primario-texto (el primario usado como texto). Si faltan, se derivan; se pueden fijar.

Así un proyecto puede tener un primario de marca claro, como el amarillo de la SF, sin perder contraste.

Tarea: «Diseñar los parámetros del estilo de un proyecto y dónde se guardan» (387).
