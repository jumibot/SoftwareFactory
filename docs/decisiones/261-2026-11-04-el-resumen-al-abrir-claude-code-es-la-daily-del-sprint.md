# El resumen al abrir Claude Code es la daily del sprint

Al abrir Claude Code, el resumen breve que hace Claude sin pedirlo (objetivo del sprint en curso, tareas en curso, lo que espera prueba o decisión, lo que hay en cola) es la daily del sprint: un sprint tiene tantas dailies como veces se abre Claude Code mientras dura.

Por qué: da nombre conocido al momento de situarse y lo separa de la revisión y planificación que se hacen al cambiar de sprint (tarea 347).
