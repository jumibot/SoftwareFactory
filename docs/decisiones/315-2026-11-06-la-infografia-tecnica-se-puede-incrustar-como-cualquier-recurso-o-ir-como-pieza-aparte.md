# La infografía técnica se puede incrustar como cualquier recurso o ir como pieza aparte

La infografía técnica animada puede ir de dos formas: incrustada en un documento, como cualquier otro recurso del catálogo, o como pieza aparte que el documento enlaza.

En las dos toma el estilo del proyecto.

Tarea: «Que cada proyecto tenga un solo estilo de documentos: una base común de maquetación para todas las skills de documentos» (385).
