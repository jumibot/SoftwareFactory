# El color de sesión de la SF no se reserva: un proyecto puede salir del mismo color

El color de sesión de la Software Factory no está reservado: un proyecto puede salir del mismo color que la SF si su estilo lo pide.

Que hoy haya menos temas que colores de sesión es circunstancial: en el futuro puede haber varios temas con el mismo color, por ejemplo varios amarillos.

Tarea: «Que cada proyecto tenga un solo estilo de documentos: una base común de maquetación para todas las skills de documentos» (385).
