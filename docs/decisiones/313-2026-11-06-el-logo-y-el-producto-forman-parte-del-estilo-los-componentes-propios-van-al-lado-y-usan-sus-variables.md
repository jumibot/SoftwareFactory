# El logo y el producto forman parte del estilo; los componentes propios van al lado y usan sus variables

El logo y el nombre del producto forman parte del estilo del proyecto: salen en la portada y el pie de los documentos, y se eligen con las muestras.

Los componentes propios de un proyecto (su CSS y su JS, por ejemplo una calculadora) van al lado del estilo: no forman parte de él ni los fija la skill de estilo, pero usan sus variables.

Tarea: «Que cada proyecto tenga un solo estilo de documentos: una base común de maquetación para todas las skills de documentos» (385).
