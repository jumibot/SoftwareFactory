# La daily se pide con /sf_daily y es una conversación

Hay una orden /sf_daily para pedir la daily en cualquier momento. En la daily, Claude hace un resumen introductorio del sprint (objetivo, en curso, lo que espera prueba o decisión, cola) y después el developer pregunta o aporta lo que crea conveniente: no es un informe cerrado, sino el arranque de una conversación.
