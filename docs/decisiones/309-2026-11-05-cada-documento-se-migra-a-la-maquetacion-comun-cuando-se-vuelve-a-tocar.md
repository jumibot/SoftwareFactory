# Cada documento se migra a la maquetación común cuando se vuelve a tocar

Los documentos existentes de la Software Factory no se migran de golpe a la skill común de maquetación: cada uno se migra cuando se vuelve a tocar por otra razón.

Tarea: «Que cada proyecto tenga un solo estilo de documentos: una base común de maquetación para todas las skills de documentos» (385).
