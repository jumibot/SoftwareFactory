# Cada documento se migra al generador único cuando se vuelve a tocar

Los documentos existentes de la Software Factory no se migran de golpe al generador único de documentos: cada uno se migra cuando se vuelve a tocar por otra razón.

Tarea: «Que cada proyecto tenga un solo estilo de documentos: una base común de maquetación para todas las skills de documentos» (385).
