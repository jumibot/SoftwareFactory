# Mejorar la skill que se usa es un paso

- **Origen:** SoftwareFactory, 2026-10-29, tarea 91. El propietario: «en las tareas de creación y/o mejora de docs en las que se usen skill se podrán mejorar estos como pasos propios de la tarea».
- **Contexto:** al escribir «Mejora continua a la Software Factory» salieron reglas nuevas de redacción (explicación hilada, frases cortas, una negrita por párrafo, sin paja) que deben llegar a las skills de documentos.
- **Decisión:** en una tarea que crea o mejora documentos con una skill, mejorar esa skill con lo aprendido es un paso de la propia tarea, no una tarea aparte. Así lo aprendido llega a la skill mientras está fresco.
- **Aplicada en:** metodología, 2 («¿Paso o tarea?»); plantilla `claude-sf.md`; `CLAUDE.md`.
