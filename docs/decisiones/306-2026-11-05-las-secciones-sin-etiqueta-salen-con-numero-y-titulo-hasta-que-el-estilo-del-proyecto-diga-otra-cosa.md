# Las secciones sin etiqueta salen con número y título hasta que el estilo del proyecto diga otra cosa

Los documentos que se migran a la skill común de maquetación toman la forma de sección que fije el estilo del proyecto.

Mientras ese estilo no se decida, una sección sin etiqueta («## Guía rápida») sale con su número y su título, sin antetítulo repetido, y no se reescribe ningún documento.

Tarea: «Que cada proyecto tenga un solo estilo de documentos: una base común de maquetación para todas las skills de documentos» (385).
