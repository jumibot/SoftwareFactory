# Temas visuales de la skill de visión

- **Origen:** SoftwareFactory, 2026-10-25.
- **Decisión:** un archivo por tema, con tonos derivados de pocos colores base y variables CSS. Temas con nombres genéricos (`morado`, `rojo`, `teal`, `colorido`). El logo y el tema elegido viven en el proyecto. Antes de crear un tema a partir de la web de una organización, la skill pregunta al autor.
- **Aplicada en:** skill `documento_vision`.
