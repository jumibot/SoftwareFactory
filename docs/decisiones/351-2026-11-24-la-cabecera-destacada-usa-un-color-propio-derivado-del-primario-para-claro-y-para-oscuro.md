# La cabecera destacada usa un color propio, derivado del primario, para claro y para oscuro

Cuando la portada se destaca con el color del proyecto, su fondo no es el primario tal cual: es un color de cabecera propio del estilo, calculado para cada tema en claro y en oscuro, menos brillante que el primario y con su texto en contraste suficiente (392).

Porque un primario vivo, como el amarillo #f5c400, a todo el ancho resulta demasiado brillante.
