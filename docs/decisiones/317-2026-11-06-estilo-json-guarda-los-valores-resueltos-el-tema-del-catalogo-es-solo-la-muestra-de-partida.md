# estilo.json guarda los valores resueltos; el tema del catálogo es solo la muestra de partida

estilo.json guarda todos los valores del estilo ya resueltos. El tema del catálogo del plugin del que se partió queda solo como origen.

Una actualización del plugin no cambia el estilo de un proyecto sin una vuelta de afinado.

Tarea: «Diseñar los parámetros del estilo de un proyecto y dónde se guardan» (387).
