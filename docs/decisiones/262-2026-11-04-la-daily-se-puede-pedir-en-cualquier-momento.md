# La daily se puede pedir en cualquier momento

Además de la daily automática al abrir Claude Code, el developer puede pedir una daily cuando quiera (con una orden de barra, propuesta /sf_daily, o pidiéndola con palabras): el mismo resumen breve del sprint en curso.

Por qué: tras una pausa, una interrupción o muchas tareas a la vez, situarse no debería exigir cerrar y abrir Claude Code (tarea 347).
