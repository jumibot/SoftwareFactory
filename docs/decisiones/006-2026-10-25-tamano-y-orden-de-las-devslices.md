# Tamaño y orden de las devslices

- **Origen:** SoftwareFactory, 2026-10-25, al planificar LecturaFàcil.
- **Decisión:** como recomendaciones generales para proponer el plan, que luego se ajusta con el propietario: cada devslice cabe en una o dos sesiones y se parte si no cabe; primero va lo necesario para comprobar lo siguiente; las integraciones caras o inciertas van al final, simuladas hasta entonces.
- **Aplicada en:** metodología, 3.4 y 3.5; especificación, 2.
