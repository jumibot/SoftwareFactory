# Plantilla: claude code como componente del backend

Estructura de partida de la [metodología de la SF, 7.4](../../skills/metodologia/references/desarrollo-de-proyectos.md). Es una plantilla adaptable: se crea solo lo necesario, y las reglas que la acompañan están en la metodología.

Propuesta para una aplicación con backend separado:

```text
backend/
├── src/
├── tests/
└── agent-runtime/
    ├── instructions/
    ├── skills/
    ├── hooks/
    ├── tools/
    └── checks/
```
